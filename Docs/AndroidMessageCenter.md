# Android 局域网查看器（第一版）

## 定位

Android 第一版是 Mac 面板的只读局域网查看器。它只在前台运行，通过系统 NSD 自动发现同一 Wi-Fi 中的 Mac，并使用连接码建立 TCP 连接。没有账户、云服务、FCM 或远程控制。

消息模型保留 `source` 字段，因此以后可以接入其他来源；第一版不提前实现来源管理或通用消息中心。

## 页面

只有一个页面：

1. 未连接时输入 Mac 显示的连接码。
2. 顶部显示连接状态。
3. `运行中 / 需要你 / 待查看` 三个筛选与数量。
4. 卡片只显示状态、标题、项目、相对时间和持续时间。
5. 底部明确“局域网 · 最近 24h”。

界面使用原生 Android 控件和高密度列表，不引入 Compose 或第三方 UI 依赖。它延续 Mac 的信息层级与绿 / 琥珀 / 蓝状态色，但不照搬毛玻璃。

## 联动边界

```text
Codex 本地状态 → Mac 安全快照 → Bonjour + TCP → Android 前台列表
```

- Mac 局域网共享默认关闭，由用户主动开启。
- Android 只消费版本化快照，不读取 Codex 私有数据文件。
- 传输时间固定为 RFC 3339 UTC 毫秒，持续时间使用整数毫秒。
- 快照不含 Prompt、摘要、源码、终端输出、访问令牌、绝对路径、分支、模型或深链。
- Android 退到后台即断开，不注册后台服务。
- 连接码只适用于可信 Wi-Fi；v1 没有 TLS，不应用于公共网络。

协议细节见 [`LANProtocol.md`](LANProtocol.md)。Android 源码位于仓库的 `android/`。

## 后续但不在第一版

真正的公网推送需要独立设计账户、设备撤销、端到端权限、滥用控制、FCM 和服务器成本。它不会与本次局域网版本混在一起，也不会因为保留了 `source` 字段而默认实现。
