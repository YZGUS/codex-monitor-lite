# Android 多来源消息中心（后续独立项目）

## 定位

Android 端是面向多个消息来源的极简收件箱，不是 Codex 的手机镜像。Codex 只是第一种 `source.kind`；以后可接构建系统、服务器告警、自动化任务或其他 Agent，而无需修改消息列表的核心模型。

## 页面

1. **消息列表**：`全部 / 需处理 / 未读` 三个筛选；每张卡只显示来源、标题、安全摘要、优先级和本地时间。
2. **消息详情**：完整安全摘要、状态变化时间线和来源信息。第一阶段只读。
3. **来源管理**：查看、静音或停用各消息来源。
4. **设备设置**：通知级别、免打扰、设备注销与隐私说明。

视觉延续 macOS 端的极简原则：高密度卡片、清晰文字层级、少量状态色。Android 使用 Material 语义组件，不照搬 macOS 毛玻璃或桌面交互。

## 联动边界

```text
Mac / 其他来源 → HTTPS 事件入口 → 云端去重与投递 → FCM → Android
```

- 云端和 Android 只消费版本化 `StandardEvent`，不读取 Codex 私有模型。
- `eventId` 用于幂等去重；`schemaVersion` 用于协议升级。
- 传输时间固定为 RFC 3339 UTC 毫秒；Android 按设备时区显示。
- 持续时间使用整数毫秒，不传本地化字符串。
- 默认事件不得包含 Prompt、源码、终端输出、访问令牌或绝对路径。
- 远程回复、授权和中断属于后续单独能力，必须先完成设备认证、端到端权限、撤销和审计设计。

当前仓库只保留协议与 `EventPublisher` 接口，不包含云端、FCM 或 Android 代码。
